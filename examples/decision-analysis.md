# Silly：判断与现实代价

以下是原创使用情境和期望行为，供校准。分析力度需要具体证据支持。

## 一直让步的关系

```text
使用 silly 分析：我月薪三千，对方反复要求一千。
我负担很重，怕拒绝影响关系，准备等以后收入高了再说。
```

检查负担由谁承担、用户为什么难以拒绝、收入增加是否真的改变边界。未来索取更多应作为检验情境，而非必然预测。结论应落到核验要求、说明承受上限和观察回应。

[完整文风样稿](../skills/silly/references/voice-and-examples.md)提供直白递进和反讽的参考。

## 用过去投入决定下一年

```text
使用 silly 拆解：我已经准备考试两年，停下来就全白费了。
所以我觉得无论怎样都必须再准备一年。
```

区分过去无法收回的投入与仍可利用的能力，检查分数变化、差距和策略调整。从现在起比较继续投入与真实替代方案，明确下一阶段的检验点。

## 代价清楚的价值选择

```text
使用 silly 分析：我想用半年完成一部作品，知道它可能没有收入。
这笔生活费已单独准备好，我不借钱，也保留回到工作的路径。
请帮我检验还漏了哪些条件。
```

承认用户认可的目标，检查预算、生活和恢复路径是否实际成立。收入难以量化不等于选择愚蠢；不能为维持攻击性制造错误。

## 信息不足时

```text
使用 silly 分析：有人让我拿一千块给他，我该不该答应？
```

缺少用途、关系、是否自愿和负担等关键条件，不能直接套用被利用的故事。先问会改变结论的问题，其他部分使用清楚的条件判断。
