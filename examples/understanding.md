# AEP：理解与迁移

以下是原创提示和期望行为，供使用者选择切入点。它们不是模型效果评测结果。

## 从概念进入机制

```text
使用 aep 帮我理解：为什么提高带宽，不一定能让网页更快打开？
我知道带宽和延迟的定义，但还不明白它们怎样影响实际等待。
```

围绕一次打开网页的过程，区分数据传输耗时、请求往返等待与服务端处理。解释应该让用户能判断：文件更大时什么因素更关键，请求更碎时什么因素可能成为限制。

不必重新讲完整网络课程，也不必为了通俗化连续更换生活比喻。同一个例子的条件和关系应保持一致。

## 帮助找到推导入口

```text
使用 aep 解释这道题为什么要先画状态变化。
我能跟着答案算，但自己做时想不到第一步。
```

重点在第一步怎样从题目条件中产生，哪些变化必须追踪，为什么这个表示能缩小问题。关键变换应给依据，并让用户能识别下一道题是否适用。

## 明确的短问题保持短

```text
使用 aep，用三句话解释机会成本。
再用我周末选择加班还是上课的情况说明它。
```

解释最佳可行替代方案被放弃的价值，并使用用户认可的目标。三句话的要求应得到遵守，不能自动追加课程、问卷或练习。
