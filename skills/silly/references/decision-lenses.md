# 判断链与心理机制

只选对当前行动有解释力的视角。下面是检验问题的工具，不是人格分类或心理诊断标准。

## 证据先于偏差标签

一个措辞只能提供线索。具体理由、实际行为或明确的决策规则才支持判断某个机制正在起作用；只有多次可访问、可比较的情境才支持“反复出现”的结论。

例如，“我不想认亏”不足以证明持有错误。需要比较继续持有的未来收益与风险，检验用户是否只因过去亏损而拒绝更好的选择。过去投入也可能留下技能、信用、资格或可利用资产；只把无法收回的部分视为沉没成本。

陈述偏差时同时给出：对应的用户理由、从理由到行动的问题、其他可能解释，以及能区分解释的证据。单次关键错误不必等两次才指出；多处类似措辞也不能凑成高置信度画像。

## 常用检验

| 判断线索 | 检验方式 | 避免误判 |
|---|---|---|
| 旧价格、旧身份决定当前价值 | 如果不知道旧值，还会作同样决定吗？当前基本条件有什么变化？ | 历史数据可能有预测价值，不能一律当作锚定 |
| 只看成功者或熟悉案例 | 总样本、失败率、筛选规则与自身条件是什么？ | 相关案例可以提供机制线索，只是不能直接替代基率 |
| “投入这么多，不能停” | 从今天算起，新增投入是否优于替代路径？ | 已积累的能力和完成前景属于未来收益的一部分 |
| “大家/专家都这么说” | 对方有什么可检验依据，适用条件是否相同？ | 合理借助专业分工和社会信息并非自动失去判断力 |
| 刚发生的事件决定长期趋势 | 拉长窗口、看反例与机制是否仍成立？ | 新事件也可能真的改变结构，不能机械回归旧常态 |
| 担心错过、急于证明自己 | 期限和稀缺是否真实？放弃了哪些核验与议价机会？ | 真正的竞争窗口可以要求迅速行动 |
| 只搜支持原方案的内容 | 哪个事实会让用户改主意？最强反对意见是什么？ | 保持立场可能来自较强证据，不一定是确认偏误 |
| “至少稳定”“肯定会好” | 什么结果仍会失败，谁承担尾部风险，控制权在哪里？ | 低波动与可靠承诺有真实价值，只需核查其成本与条件 |
| “至少做点什么” | 行动怎样改变结果？信息收集和暂缓能否更好？ | 有反馈的小试验可能比无限等待更理性 |

情绪是价值、压力和需要的信号；当它替代事实或概率依据时才需要纠偏。对明显冲动，可以先缩小不可逆承诺，再继续分析，而非否认情绪。

## 目标形成与群体影响

区分实际结果、身份象征和暂时解除不适。用户可能同时追求收入、能力、归属与认可；说明哪个目标真正推动当前行动，不预设面子或关系价值为零。动机判断必须对应用户表达和行为，未确认的解释不能写成揭穿后的事实。

共识要看信息如何生成。十个人独立观察得到相同结论，与十个人转述同一个成功故事，证据结构不同。检查原始信息、参与者激励和未被传播的失败样本；合理借助专业知识或社会信息不自动构成错误。

多种因素可能共同推动同一行动：现金流压力使用户难以等待，权威背书降低核验意愿，成功者故事制造紧迫感，已作承诺提高退出难度。只挑有证据、能改变结论的关系解释，不凑满偏差名称。

## 按处境补关键约束

- **投资与资产：** 资金来源、期限、仓位、现金流、流动性、可承受损失、入场依据与退出条件。长期看好不自动支持任何价格和杠杆。
- **住房：** 居住需要、持有时长、总成本、家庭现金流、租住替代、通勤与政策。首付够不等于后续负担可持续。
- **学习与考试：** 基础、进步证据、资格要求、竞争基率、投入上限、失败后路径与技能积累。身份标签与实际回报要分别看。
- **职业：** 收入、可迁移能力、成长、健康与家庭约束、真实备选、离职成本。平台资源与个人能力分别评估。
- **关系：** 双方表达的需要、权责、承诺、家庭负担、边界与沟通。信任、照顾和共同生活本身可以创造价值，不把关系压缩成一次交易。

不必逐项盘问。只补充会改变当前结论的条件；具体价格、政策与竞争数据需要核实后使用。

## 反事实与复盘

可选择一两个有判别力的问题：

- 若无人知道这次选择，用户还会这么选吗？用来区分目标与认可需求，不能预设面子没有价值。
- 若尚未投入，今天还会加入吗？再把已有可利用资产放回比较。
- 若最关键承诺落空，用户还能承担什么结果？如何降低脆弱性？
- 同样建议给处境相同的朋友，是否会变化？差异来自真实条件还是自我例外？

复盘按当时信息和可选行动评价决策，不用一次成功证明所有判断正确，也不用一次失败证明用户愚蠢。
