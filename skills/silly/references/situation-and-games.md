# 处境、利益与博弈

用能影响现实选择的机制，不堆理论名称。只有多方行动互相影响时才需要博弈分析；一般单人权衡不强行建模。

## 建立最小局面

确定参与者、目标、资源约束、可选行动、信息、行动先后与是否重复互动。分别标明用户报告、外部核验与模型假设。不了解对方偏好时给出不同偏好下的回应分支。

先判断是否值得参与：用户通过什么机制获益，需要什么能力和位置，能否改变不利条件或选择其他路径。不要刚接到方案就替用户优化进入方式；拒绝参与、分阶段进入和争取更好条件都应作为现实选项。

分别看控制权、奖励、失败责任和退出权归谁。提出建议的人若先取得收益，而用户要长期承担后果，应核验建议是否与用户的结果一致；利益不一致需要调整责任或核验条件，不能直接推出恶意。

## 选用相关机制

| 机制 | 要看什么 | 可以改变什么 |
|---|---|---|
| 激励与利益冲突 | 谁在推荐，谁因成交获益，收益是否与用户长期结果相关？ | 独立核实、披露费用、用结果而非头衔检验主张 |
| 信息不对称 | 哪些条件只有一方知道，信息是否可验证？ | 要求书面事实、小额试验、第三方核验 |
| 议价与替代方案 | 双方不达成协议会怎样，谁有真实替代，谁的时间压力更大？ | 扩展备选、调整顺序、提高退出能力；不要虚构底牌 |
| 承诺与可信性 | 承诺者将来是否仍有履行激励，违约成本谁承担？ | 分阶段兑现、明确责任与条件，核实执行机制 |
| 重复互动与声誉 | 一次获利是否损害长期合作，双方能否观察履约？ | 建立可验证反馈、互惠规则和清楚边界 |
| 协调与共同收益 | 双方是否目标兼容但缺乏沟通或分配方案？ | 提出能同时改善处境的安排，再讨论收益分配 |
| 竞争与拥挤 | 入场者增加是否降低回报，名额或资源是否固定？ | 核查竞争基率，寻找差异化与替代路径 |
| 外部性与规则 | 家人、同事或公众承担了哪些未被计入的成本？ | 将责任与关系成本纳入方案，不只算自己收益 |

“对方能等而我等不起”需要现金流、截止时间或选择空间的证据。避免把一切优势都解释成恶意；结构性利益冲突可在无人蓄意操控时存在。

## 比较行动后的局面

对有意义的候选方案追问：用户先行动后，对方可如何回应？新承诺会增强合作，还是让用户更难退出？短期收益是否换来长期依赖？暂缓是否能获得信息，还是错过真实机会？

不默认所有互动为零和。信任、合作、共同生产与互惠可能创造额外收益；强硬也有损害合作的代价。平衡取决于用户目标与可验证局面。

最坏结果用于检查承受边界，不要求用户一律选择最保守方案。概率不明时用情景与条件比较；对结论最敏感的未知条件优先核验。

## 识别压力机制

仅在有证据时分析制造稀缺、夸大成功基率、以身份或关系压迫承诺、让用户先承担不可逆成本等机制。写清具体行为、获益路径、其他解释和核验方式。不能因对方获利就推断欺骗，也不能把正常劝说自动定性为操控。

建议优先改变可控制的条件：补事实、扩替代、分阶段承诺、限制暴露、争取信息和时间、约定退出。目标是提高用户的判断与选择能力，不是教其操控、欺骗或无条件赢过别人。
